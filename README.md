# interview_sandbox

Python sandbox for live coding.

## Commands

```bash
make install   # create default_venv and install pinned packages
make test      # run the tests (make tests also works)
make lint      # check code with ruff
make format    # format code with ruff
make run       # print Hello, World!
make update    # upgrade packages and re-pin requirements.txt
make clean     # delete caches
make           # list all commands
```

To use the venv in your shell:

```bash
source default_venv/bin/activate
```

## Dependencies

- `requirements.in` lists the packages this project uses directly. Add new packages here.
- `requirements.txt` pins every installed package to an exact version. It's generated by `make update`, so don't edit it by hand.
